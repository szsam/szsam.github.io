  • 2024 - 2026
    Aithos: LLM-Agent Triage of Static Analysis Alerts
    • Designed an LLM agentic framework that classifies SAST alerts from natural-language guidelines, dynamically retrieving program context through LLVM-based analysis primitives.
    • Added a feedback loop that turns developer corrections into reusable, repository-specific examples.
    • Preserved 97.5% of true positives while filtering 78.0% of false positives across four SAST tools on real-world C/C++ projects, outperforming a state-of-the-art baseline.
    • Uncovered 90 unknown bugs in 28 popular Debian packages; fixes merged in zstd, util-linux, pciutils.
  • 2023 - 2024
    Detecting 709 Defects in Open-Source Embedded Software with CodeQL
    • Ran CodeQL across 258 GitHub projects; found 709 true defects at a 34% false positive rate, 535 (75%) likely security vulnerabilities (e.g., null pointer dereference, buffer overflow).
    • Got 376 (53%) defects confirmed by maintainers, mainly by submitting and merging pull requests to projects including those by Microsoft, Amazon, and the Apache Foundation; 2 CVEs issued.
    • Opened pull requests adding CodeQL scans to CI pipelines; 37 (71% of active repositories) merged.
  • 2022 - 2023
