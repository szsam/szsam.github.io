  1. ISSTA
    Finding 709 Defects in 258 Projects: An Experience Report on Applying CodeQL to Open-Source Embedded Software (Experience Paper)
    Mingjie Shen, Akul Abhilash Pillai, Brian A. Yuan, James C. Davis, and Aravind Machiry
    Proc. ACM Softw. Eng., 2025
    Abs DOI arXiv Bib

    In this experience paper, we report on a large-scale empirical study of Static Application Security Testing (SAST) in Open-Source Embedded Software (EMBOSS) repositories. We apply CodeQL to 258 EMBOSS projects, characterize the defects it reports, and share the lessons learned about using SAST on large real-world embedded codebases.
